Если вы только начинаете работу — рекомендуем начать с раздела [Жизненный цикл клики]({{ docs_root }}/chyt/user-guide/explanation/cliques/overview.md#lifecycle). Это поможет понять, какие шаги нужно пройти, чтобы подготовить клику к выполнению SQL-запросов, и что происходит на каждом этапе.
