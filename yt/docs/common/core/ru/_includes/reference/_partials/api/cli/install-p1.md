# {{product-name}} CLI

CLI состоит из нескольких частей. Основная часть написана на Python и является платформонезависимой.
Для использования [YSON]({{ docs_root }}/core/reference/storage/yson)-формата представления данных нужно установить так называемые YSON-bindings. Они представляют собой отдельную библиотеку, доступную только под Linux и Mac OS. Данная библиотека содержит внутри себя бинарный модуль, написанный на C++.

Узнать версию установленной CLI можно, вызвав команду `$ yt --version`, это самый простой способ проверить работоспособность CLI.
