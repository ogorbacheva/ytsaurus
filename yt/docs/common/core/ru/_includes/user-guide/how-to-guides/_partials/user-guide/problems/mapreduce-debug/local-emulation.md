## Локальная эмуляция запуска джоба

Вы можете эмулировать запуск джоба на любом компьютере, например на разработческом сервере. Подробнее о локальной эмуляции джоба см. в разделах [Утилита для локальной отладки джобов]({{ docs_root }}/core/user-guide/how-to-guides/problems/jobtool) и [Диагностика медленных джобов]({{ docs_root }}/core/user-guide/how-to-guides/problems/jobshell-and-slowjobs).
